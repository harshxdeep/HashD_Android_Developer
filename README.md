## 🚀 Deployment

### GitHub Pages (Current)
The portfolio is automatically deployed via GitHub Pages from the `main` branch.

### Local Development
```bash
# Clone the repository
git clone https://github.com/harshxdeep/HashD_Android_Developer.git

# Navigate to directory
cd HashD_Android_Developer

# Open in browser (no build required)
open index.html
# or use a local server
python3 -m http.server 8000
```

### Deploy to Other Platforms

**Vercel:**
```bash
npm install -g vercel
vercel --prod
```

**Netlify:**
```bash
npm install -g netlify-cli
netlify deploy --prod --dir .
```

**Custom Server:**
Simply upload all files to your web server root directory.

## 🎯 Customization Guide

### Update Profile Information
Edit `index.html` and update:
- Line 6: Title and meta description
- Line 124-128: Name and headline
- Line 151-153: Social media links

### Change Color Scheme
Edit `style.css`:
- Primary: `#38bdf8` (cyan)
- Secondary: `#3DDC84` (green)
- Background: `#0f172a` (dark blue)

### Update GitHub Stats
Edit `index.html` line 507:
```html
<img src="https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME&...">
```

### Modify Chatbot Behavior
Edit chatbot section in `index.html` (lines 596-770):
- Update conversation flow
- Change Formspree ID (line 745)
